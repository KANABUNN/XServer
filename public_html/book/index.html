貸し部屋予約

カレンダーで利用日を選んだあと、各日付ごとに部屋と利用時間を設定して予約できます。利用時間は 9:00〜20:00 の範囲です。

  1. 1利用者情報
  2. 2日付選択
  3. 3時刻・部屋
  4. 4規約同意

1. 利用者情報

メールアドレス・団体名を入力してください。

2. 利用日の選択

予約可能期間は本日から2日後〜2か月先までです。複数日を選択できます。

読み込み中... 予約状況を取得しています。
選択可 一部の部屋のみ空き 満室 選択不可 選択中

利用日をクリックして選択してください。選択後に日付ごとの部屋・利用時間を設定できます。

3. 日付ごとの設定

選んだ各日付について、部屋と利用開始 / 終了時刻を設定してください。

4. 規約の確認

内容を確認し、同意したうえで送信してください。
